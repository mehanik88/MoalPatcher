## Что делает Moal Patcher

Moal Patcher применяет патч драйвера Wi‑Fi на совместимых головных устройствах Desay. Патч помогает предотвратить внезапные зависания, после которых головное устройство может сброситься до заводских настроек.

Для применения и отката нужен системный доступ. Строка **«Доступ»** показывает, есть ли он, а **«Состояние»** показывает, активен ли патч после текущей загрузки. Если вы уже применили патч Wi‑Fi через другое приложение, повторно применять его не нужно.

## Как пользоваться

- **«Применить»** загружает исправленный модуль Wi‑Fi.
- **«При загрузке»** включает автоматическое применение патча при запуске головного устройства.
- **«Откатить»** возвращает штатный модуль Wi‑Fi. Если хотите сохранить откат после перезагрузки, выключите **«При загрузке»**.
